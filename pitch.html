Проблема · Решение · Модель
Проблема

Рынок переплачивает
за то, что не работает

  • ✗
    Каждый ресторан — своя карта, своё приложение. У гостя 10+ программ
  • ✗
    Скидки убивают маржу. Ресторан приучает гостя к «дешевле», а не к ценности
  • ✗
    CRM не используются персоналом. ROI не считается. «Лучший гость» не идентифицируется
  • ✗
    Все решения локальны — ценность не выходит за пределы одного ресторана
Решение

Гость — это актив.
Его статус переносим.

  • ✓
    Один QR-код у гостя — показывает его в ресторане. Ресторан сканирует. Данные в базе.
  • ✓
    Единая база — каждый ресторан с подпиской видит всех гостей системы
  • ✓
    Статус, а не скидки — 5 уровней (New → Regular → Insider → VIP → Legend)
  • ✓
    Предложения по уровню — ресторан фильтрует базу и отправляет нужной аудитории

Правовой анализ

152-ФЗ: полностью легально,
выполнимо за 2 недели

Вывод: Обработка данных о визитах и предпочтениях — стандартная коммерческая деятельность. Аналог: программы лояльности Сбера, Яндекса, Wildberries. При правильном запуске — нулевой правовой риск.
Обязательные действия до запуска
  • !
    Уведомить Роскомнадзор о намерении обрабатывать ПД. Обязательно с 30.05.2025. Срок: 2–5 дней.
  • !
    Хранение только на российских серверах (152-ФЗ с 01.07.2025). Выбор: SberCloud, Яндекс.Облако, VK Cloud.
  • ✓
    Политика конфиденциальности — публичный документ. Цели, сроки хранения, права субъектов.
  • !
    Отдельное согласие на ПД (с 01.09.2025) — не чекбокс «по умолчанию», отдельная форма.
  • ✓
    Назначить ответственного за ПД — сотрудник или ИП-основатель. Внести в реестр РКН.
  • ✓
    Договор-оферта для ресторанов — регулирует доступ к базе, конфиденциальность гостей.
Что пользователь принимает при регистрации
  • ✓
    Согласие на обработку ПД — Telegram ID, история визитов, сумма чека (отдельная форма)
  • ✓
    Пользовательское соглашение — правила платформы, статусная система, права
  • ✓
    Согласие на предложения ресторанов — отдельная галочка «Получать уведомления». Отзывается в кабинете.
  • ✓
    Cookie-баннер — уведомление при первом входе
